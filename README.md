# AIMIA

AIMIA is a rhythm game for Roblox, written in Luau. It is based on Rhythia, the free and open source rhythm game by Rhythia and its contributors. Thank you to all of them for sharing it.

AIMIA's changes and additions are by ozkstrap, 2026.

## What is in this repository

This is the game's code: everything in `Aimia`, which runs as `ReplicatedStorage.Aimia` in the place. The files are laid out the Rojo way: a script that has scripts under it is a folder with an `init.luau` file.

These are not included:

- songs, covers and map charts. They belong to their artists and mappers.
- pictures, sounds and other assets. The asset ids in the code point at uploads that only the original experience can load.
- the code of the Roblox experience AIMIA runs in: its menus, saving, leaderboards, multiplayer server and moderation tools.
